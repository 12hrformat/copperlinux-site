What is Copper Linux?

Copper Linux is an independent, open source Linux distribution for web, code, school and everyday work. The desktop is ready to use, Ethernet works out of the box, and packages are installed with ingot — a package manager written for Copper.

Copper Linux pre-releases are published on GitHub. There is no stable ISO yet; the releases are meant for testing in a VM or on real hardware.

ingot package manager

ingot is Copper Linux's own package manager. Its copper-ingot-repo holds packaged tools, desktop apps, network utilities, libraries and fonts. Browse every package in the site's ingot section.

Download Copper Linux

Get the newest Copper Linux pre-release, or see all releases. Attach the ISO to a VM with at least 2 GB of RAM and boot from it — nothing is installed unless you choose to install it.

Frequently asked questions

What is Copper Linux?

Copper Linux is a small, fast, independent Linux distribution for daily use. It is built by one maintainer with a few contributors and ships with ingot, Copper's own package manager.

Where can I download Copper Linux?

Copper Linux pre-releases are published on GitHub. Use the latest release link on this site to download the newest Copper Linux ISO.

What is ingot?

ingot is Copper Linux's own package manager. Its repository holds packaged tools, desktop apps, network utilities, libraries and fonts that can be installed on Copper Linux.

Is Copper Linux free?

Yes. Copper Linux is open source and free to download, use, modify and contribute to.

Who makes Copper Linux?

Copper Linux is built by one maintainer, 12hrformat, with help from a few contributors.
